# OpenRouter Model Manager

A full-stack app for managing and chatting with AI models via OpenRouter, with a React frontend and Express API backed by PostgreSQL.

## Run & Operate

- Workflows: `artifacts/api-server: API Server` (port 8080) and `artifacts/model-manager: web` (port 19606)
- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from the OpenAPI spec
- `pnpm --filter @workspace/db run push` — push DB schema changes (dev only)
- Required secrets: `OPENROUTER_API_KEY` — OpenRouter API key (https://openrouter.ai/keys)
- Runtime-managed: `DATABASE_URL` — auto-provisioned PostgreSQL connection string

## Stack

- pnpm workspaces, Node.js 24, TypeScript 5.9
- API: Express 5
- DB: PostgreSQL + Drizzle ORM
- Validation: Zod (`zod/v4`), `drizzle-zod`
- API codegen: Orval (from OpenAPI spec)
- Build: esbuild (CJS bundle)
